# Health in Context

## A Georgia Community Health Profile

**Developed by:** Kalyn Newton, MPH Scholar, B.S.  
**Institution:** Morehouse School of Medicine  
**Course:** Advanced R | Fall 2026

## Project Overview

Health in Context is an interactive public health data story examining socioeconomic vulnerability, hypertension prevalence, and health insurance coverage across Georgia.

The product is designed for public health practitioners, healthcare leaders, and decision-makers to support community health assessments, preventive healthcare planning, and resource allocation.

## Data Sources

- CDC/ATSDR Social Vulnerability Index (2022)
- CDC PLACES (2025 release)
- U.S. Census Bureau American Community Survey (2025 1-Year Estimates, Table S2701)
- U.S. Census Bureau Cartographic Boundary Files (2022)

## Methods

The project uses descriptive analysis, data cleaning and validation, geographic joins, percentile-based socioeconomic vulnerability classification, and tertile-based hypertension prevalence classification.

Visualizations include an interactive bivariate choropleth map, a corresponding static map, and a stacked bar chart examining health insurance coverage among working-age adults.

## Project Scope and Development

The project evolved from an initial exploration of healthcare infrastructure and hypertension prevalence into a statewide descriptive community health profile. The final scope emphasizes socioeconomic vulnerability, geographic disease burden, and health insurance coverage as contextual indicators relevant to preventive healthcare accessibility.

## Accessibility and Ethics

The product incorporates color vision deficiency assessments, alternative text, static visualization alternatives, descriptive labels, written interpretations, and responsive website design.

All analytical datasets contain publicly available, aggregated information. Findings represent descriptive population-level patterns and should not be interpreted as individual-level associations or causal relationships.
